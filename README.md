# ¡Infla y Gana! — Paseando por la Baja

Juego promocional para móviles, tabletas y computadoras. No incluye preguntas ni datos educativos: el jugador registra su teléfono, infla un globo mediante toques y descubre su resultado.

## Archivos
- `index.html`
- `logo-paseando-por-la-baja.jpg`

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube ambos archivos a la raíz del repositorio.
3. Ve a Settings → Pages.
4. Selecciona Deploy from a branch, rama `main`, carpeta `/ (root)` y guarda.
5. Usa la URL publicada por GitHub Pages.

## Importante sobre antifraude y probabilidades
El prototipo bloquea el teléfono repetido solo en el mismo navegador mediante localStorage. El sorteo de 20% también se ejecuta en el navegador; una persona puede borrar los datos, usar otro dispositivo o modificar el código. Para una promoción oficial se requiere backend/base de datos, validación de teléfono, sorteo del lado del servidor, folios únicos y registro de canjes. GitHub Pages por sí solo no puede garantizar esas medidas.

Los premios principales solo se canjean en viajes realizados durante octubre; define las fechas exactas, vigencia, disponibilidad y condiciones en las bases oficiales. Para vino, verifica edad legal y normativa aplicable y no dirijas la promoción a menores.
