Control de participaciones

Esta versión bloquea un teléfono repetido en el mismo navegador mediante almacenamiento local. No impide borrar datos, cambiar de dispositivo o modificar el código. El porcentaje del 20 % se calcula en el navegador y no es un sorteo verificable. Para controlar duplicados entre dispositivos y validar folios de forma segura, hace falta un backend y una base de datos compartida.
